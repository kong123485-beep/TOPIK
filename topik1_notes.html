📝 TOPIK I (初級) 一頁 A4 核心筆記

目標：高效衝刺 1、2 級｜全選擇題無寫作

一、終結詞尾（名詞與動/形現在式）

1. 名詞結尾

  • 名詞 + 입니다 / 입니까?：是...嗎？（正式高規格）
  • 名詞 + 이에요 / 예序：是...（日常非正式｜有尾音用 이에요 / 無尾音用 예요）

2. 動詞/形容詞結尾

  • 動/形 + ㅂ니다 / 습니다：正式型（無尾音用 ㅂ니다 / 有尾音用 습니다）
  • 動/形 + 아요 / 어要素：口語型（母音 ㅏ, ㅗ 用 아요 / 其他用 어요）

二、時態與否定

  • 過去式：動/形 + 았/었/했어요
  • 未來式/打算：動/形 + -(으)ㄹ 거예요
  • 普通否定：안 + 動/形（不...）｜ 動/形 + -지 않아요
  • 能力否定：못 + 動（不能/沒辦法...）｜ 動 + -지 못해요

三、核心連接詞尾（句子相連）

  • 並列/順序：動/形 + -고（和、然後）
  • 轉折：動/形 + -지만（雖然...但是...）
  • 原因：動/形 + -아서/어서（因為...所以... ※後句不可接命令或共動句）
  • 假定：動/形 + -(으)면（如果...的話）

四、必考文法助詞

  • 이/가：主格助詞（強調主詞本身）
  • 은/는：主題助詞（強調對比或主題介紹）
  • 을/를：受格助詞（動作的目的物/對象）
  • 에：定點時間、去向（例：1시에, 學校에 가요）
  • 에서：動態場所（在某處做某事，例：學校에서 공부해요）
  • (으)로：工具、方向（往某處 / 用某工具）
  • 에게 / 한테：與格助詞（給/對某人做某事）

五、常考疑問詞（聽力、閱讀前4題必考）

  • 언제（什麼時候）→ 答案選時間/日期/點鐘
  • 어디（哪裡）→ 答案選場所/地點
  • 누구（誰）→ 答案選人物/職業/關係
  • 무엇 / 뭐（什麼）→ 答案選物品/具體動作
  • 어떻게（怎麼做）→ 答案選方法/交通工具
  • 왜（為什麼）→ 答案選含有 -아서/어서 的原因

六、閱讀測驗三大核心技巧

1. 第 31-33 題（選主題）

  • 關鍵：尋找重複出現次數最多的單字。
  • 例：文中出現 사과(蘋果)、바나나(香蕉)，答案直接鎖定 과일(水果)。

2. 第 34-39 題（短文填空）

  • 關鍵：注意空格前後的副詞與接續詞。
  • 看到 그래서(所以) 找因果；看到 그러나/하지만(但是) 找反義詞。

3. 第 40-42 題（圖表對照題）

  • 關鍵：不需要翻譯全文，直接玩對對碰。
  • 拿選項去跟圖表的 日期(일시)、金額(요금/가격)、地點(장소) 逐字核對。

七、高頻對比副詞（加分關鍵）

  • 아주 / 매우 (非常) ｜ 조금 (一點點)
  • 일찍 (早早地) ｜ 늦게 (晚晚地)
  • 같이 / 함께 (一起) ｜ 혼자 (獨自)
  • 가장 / 제일 (最...)
